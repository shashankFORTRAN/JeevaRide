# 🚑 JeevaRide

## Rural Emergency Transportation Network

JeevaRide is a project concept designed to help people in rural areas find emergency transportation quickly.

### 🎯 Problem

People living in rural areas may face difficulties finding transportation during medical emergencies.

### 💡 Our Idea

JeevaRide connects people who need emergency transportation with nearby transport providers.

### 🚨 Emergency Situations

- ❤️ Heart Attack
- 🧠 Stroke
- 🤰 Pregnancy Emergency
- 🚗 Accident
- 🐍 Snake Bite
- 🚑 Other Emergencies

### ⚙️ Current Prototype

The current prototype allows a user to enter:

- Patient name
- Pickup location
- Emergency type
- Destination hospital

The application then creates an emergency request.
